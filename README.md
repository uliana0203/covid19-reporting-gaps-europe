# Reporting gaps in European COVID-19 surveillance

This repository accompanies the manuscript **“Characterizing and reconstructing weekly COVID-19 surveillance reporting gaps across Europe”** by Uliana Zbezhkhovska and Dmytro Chumachenko.

The study examines missing reports and the reconstruction of COVID-19 surveillance series for 46 European countries during 2020–2025. Ukraine is used as an applied case study. Missing reports are distinguished from reported zeros.

## Analysis

The notebook aggregates WHO records into weeks, constructs population-adjusted rates, describes and clusters country reporting-continuity profiles, evaluates reconstruction methods under artificial contiguous gaps, and compares selected Ukrainian WHO counts with national surveillance reports. Reconstructed values are estimates of reported series under specified assumptions, not confirmed infections.

## Obtain the input data

Download WHO COVID-19 case and death data from the [WHO COVID-19 dashboard](https://data.who.int/dashboards/covid19/data), and World Bank population data for [Population, total (SP.POP.TOTL)](https://data.worldbank.org/indicator/SP.POP.TOTL). Put the corresponding CSV files in the same directory as the notebook using these exact names:

- `WHO-COVID-19-global-daily-data.csv`
- `API_SP.POP.TOTL_DS2_en_csv_v2_379644.csv`

The notebook reads local files; it does not download or rename them. The manuscript reports that the WHO snapshot was downloaded on 20 September 2026. WHO and World Bank data may be revised, so later downloads may differ from the files used in the study.

Selected Ukrainian national surveillance figures are transcribed in the notebook from official public-health releases. The datasets are not included in this repository and remain subject to the terms of their original providers.

## Run the notebook

The notebook metadata identifies Python 3.11.8. The original package versions have not been confirmed.

1. Place both required CSV files beside the notebook.
2. Install the packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start Jupyter in that directory:

   ```bash
   jupyter notebook
   ```

4. Open the notebook, select a Python kernel and run the cells in order. Model fitting and bootstrap calculations may take time.

The saved notebook contains an ordered run without recorded cell errors. Key manuscript tables and cluster summaries have been checked against the saved run. A complete independent reproduction in a separate environment has not yet been completed.
