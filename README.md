# Reporting gaps in European COVID-19 surveillance

This repository accompanies the manuscript **“Characterizing and reconstructing weekly COVID-19 surveillance reporting gaps across Europe”** by Uliana Zbezhkhovska and Dmytro Chumachenko.

The study examines reporting gaps and reconstruction of weekly COVID-19 surveillance series for 46 European countries during 2020–2025, with Ukraine as an applied case study. Missing reports are distinguished from reported zeros.

## Analysis

The notebook aggregates WHO case and death reports into weeks, calculates population-adjusted rates, clusters reporting-continuity profiles, and evaluates reconstruction methods using artificial gaps. It also compares selected Ukrainian WHO reports with national surveillance data. Reconstructed values are estimates of reported series under the specified methods; they are not confirmed infections.

The notebook reads the compressed WHO file directly. Tables are displayed in the notebook rather than automatically exported. Figure cells save PNG files in the working directory and overwrite files with the same names.

## Data sources

- **COVID-19 surveillance:** [WHO COVID-19 dashboard](https://data.who.int/dashboards/covid19/data). The manuscript reports that the WHO snapshot was downloaded on 20 September 2026. WHO surveillance data may be revised over time.
- **Population:** [World Bank, Population, total (SP.POP.TOTL)](https://data.worldbank.org/indicator/SP.POP.TOTL).
- **Ukrainian national surveillance:** selected figures from official public-health releases are transcribed in the notebook and listed in `ukraine_national_surveillance.csv`. September week dates are assigned in the analysis from relative descriptions in the source.

The WHO and World Bank datasets remain subject to their respective providers’ terms and attribution requirements.

## Run the notebook

The notebook metadata identifies Python 3.11.8. Package versions in `requirements.txt` are not pinned.

1. Clone or download this repository and keep the notebook and data files in the same directory.
2. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start Jupyter:

   ```bash
   jupyter notebook
   ```

4. Open `covid19_reporting_gaps_analysis.ipynb`, select a Python kernel, and run the cells in order. Model fitting and bootstrap calculations may take time.
